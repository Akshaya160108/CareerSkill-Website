# CareerSkill

CareerSkill is a React + TypeScript web application that helps students explore career paths, identify important skills, and build a practical learning roadmap.

## Features

- Student profile setup
- Career goal selection
- Career-specific skill recommendations
- Learning roadmap
- Project ideas
- Interview preparation guidance
- Responsive UI for desktop and mobile
- Browser local storage for saving profile/progress

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Radix UI
- Lucide React
- Wouter
- TanStack Query

## Run locally

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Open the URL shown by Vite, normally:

```text
http://localhost:5173
```

### 3. Create a production build

```bash
npm run build
```

### 4. Preview the production build

```bash
npm run preview
```

## Type checking

```bash
npm run typecheck
```

## Deployment

The project is a standard Vite single-page application and can be deployed to GitHub Pages, Vercel, Netlify, or another static hosting provider.

## Original live version

The application was originally developed and tested on Replit. The repository version removes the Replit-specific workspace dependencies and environment requirements so it can be installed and run as a standalone project.
